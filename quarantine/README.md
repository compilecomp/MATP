# Quarantine

Non-compliant code awaiting repair or deletion lives here (CEP&CC 32.13). Quarantined code is excluded from builds, links, ships, and benchmarks. Every quarantined item requires a `QUARANTINE.md` manifest with reason, violated rule, owner, ticket, deadline, and disposition. Quarantine is temporary; expired items are exterminated. Phase 1 contains no quarantined code.
